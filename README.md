# Generative-AI-Chatbot 

An intelligent AI chatbot built using **LangGraph**, **Google Gemini**, **LangChain** and **Streamlit**.

Generative-AI-Chatbot is designed to provide a modern conversational experience with persistent chat history, multiple conversation management, memory, and tool integration capabilities.

---

## 🚀 Features

### 💬 Multi-Conversation Support

* Create and manage multiple chat sessions.
* Switch between conversations seamlessly.
* Persistent conversation history.

### 🏷️ Smart Conversation Titles

* Automatically generates readable conversation names.
* Replaces long UUID thread IDs with meaningful titles.

### 🧠 Conversation Memory

* Maintains context throughout the conversation.
* Powered by LangGraph state management.

### 🗑️ Conversation Management

* Delete unwanted conversations.
* Clean and organized sidebar experience.

### ⚡ Real-Time Streaming

* Stream AI responses token-by-token.
* Provides a smooth user experience.

### 🔄 Persistent Checkpointing

* Conversation states are stored and restored automatically.
